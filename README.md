# bimatrix_stochastic_game.py — равновесия в биматричных играх

Один файл с двумя способами решения биматричных игр (в том числе стохастических, со случайными выигрышами):

1. **Равновесие по Штакельбергу** — лидер фиксирует (смешанную) стратегию, последователь отвечает. Работает для матриц **любой размерности** m×n.
2. **Равновесие по Нэшу** в смешанных стратегиях — алгоритм **Лемке–Хоусона**. Рассчитан на **квадратные** игры (N×N).

## Установка

```bash
pip install numpy scipy
```

Нужен Python 3.8+ и scipy ≥ 1.6 (используется `linprog` с методом `highs`).

## Быстрый старт

```bash
python bimatrix_stochastic_game.py
```

Запускает демо на игре «Конкуренция сетей фитнес-клубов» 6×6: выводит матрицы выигрышей, равновесия по Штакельбергу (для каждого из игроков в роли лидера) и равновесие Нэша по Лемке–Хоусону.

## Соглашения о матрицах

- `A[i, j]` — выигрыш игрока 1 (выбирает строку `i`), `B[i, j]` — выигрыш игрока 2 (выбирает столбец `j`). Обе матрицы одного размера m×n.
- Игра со случайными выигрышами N(μ, σ²) переводится в обычную по квантильному критерию: элемент = (μ − z·σ), где z — квантиль уровня α (например, z = 1,645 при α = 0,95).


## Ограничения и известные особенности

- **Штакельберг:** оптимальная стратегия лидера обычно лежит на границе, где последователь безразличен между двумя ответами (допущение SSE). На практике лидер сдвигает `x` внутрь области на малое ε, теряя O(ε) выигрыша.
- **Лемке–Хоусон:** реализация рассчитана на квадратные игры. Если равновесие не найдено, функция возвращает `None`.
- В функции `read_matrices` матрица B вводится размером M×N, а в остальных функциях файла B имеет тот же размер, что и A (m×n); для квадратных игр различие несущественно.
